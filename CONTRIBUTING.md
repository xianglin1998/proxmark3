# Contributing (pm5-f0-cep)

This default branch adds experimental **Flipper Zero Type-C CEP** support for Proxmark5.

Full contributor guide (FAP + firmware, safety, PR flow):

→ https://github.com/limerx/Proxmark5_FlipperZero_FAP/blob/f0-cep-autopwn/CONTRIBUTING.md

CEP notes: [`docs/F0_CEP_FLIPPER.md`](docs/F0_CEP_FLIPPER.md)

## Quick rules

- Target **Proxmark5 only** when flashing this branch.
- Open Issues / PRs here for CEP / armsrc problems; use the FAP repo for Flipper UI issues.
